# GreenPlan: панели, кнопки и поля интерфейса

Актуально на 20 октября 2026 года. Описан текущий интерфейс из `apps/web/src`, включая вкладки «Тур» и «Рендер». Поля появляются в зависимости от открытого проекта, выбранного объекта и готовности расчёта. Этот файл описывает интерфейс; устройство приложения — в [CURRENT_ARCHITECTURE.md](CURRENT_ARCHITECTURE.md).

## 3. Полоса разделов рабочего пространства

Источник: `components/Workspace.tsx`.

| Раздел | Содержимое |
|---|---|
| Интерпретация | Сведения о файле, категории объектов, слои и ручная корректировка классификации. |
| Ограничения | Допустимая область посадки и запретные зоны. |
| Генерация | Породы, стратегия и параметры запуска. |
| Результат | Итоговая итерация, метрики, соответствие, газон, причины отклонений и переход к аудиту. |
| « / » | Скрытие и раскрытие левой панели на настольном экране. |
| Конфигурация | Открытие пошаговой конфигурации проекта. |

Цифры и значки возле разделов показывают число проблем, готовность данных, активность расчёта или количество деревьев в результате. Одновременно открывается один раздел левой панели. Границу панели можно перетаскивать для изменения ширины.

### Интерпретация

Источник: `components/panels/LayersPanel.tsx`.

- Имя файла, число объектов и слоёв, единицы чертежа — сведения об импорте.
- Группы категорий — здания, дороги, сети, существующая растительность, граница и прочие объекты.
- Флажок видимости слоя/группы управляет отображением.
- Список категории слоя меняет его семантическую классификацию, используемую последующими расчётами.
- Уверенность, предупреждение и сведения об источнике помогают найти слои для ручной проверки.
- «Показать все слои» раскрывает полный список; предупреждение о непроверенных слоях ведёт к проверке.

### Ограничения

Источник: `components/panels/ConstraintsPanel.tsx`.

| Переключатель / данные | Значение |
|---|---|
| Зона посадки | Показ допустимой области. |
| Запретные зоны | Показ буферов и ограничений от объектов. |
| Существующее озеленение | Показ исходных деревьев и кустарников. |
| Исходный чертёж | Показ CAD-подложки. |
| Площади, правила, предупреждения | Сводка построенной геометрии и условий применения правил. |

Переключатели отображения не изменяют нормативные расстояния.

### Генерация

Источник: `components/panels/GeneratePanel.tsx`.

| Поле | Значение |
|---|---|
| Породы | Разрешённые породы деревьев/кустарников. Рядом отображается радиус взрослой кроны; «?» означает непроверенный нормативный статус породы. |
| Стратегия | Сбалансированная, максимум деревьев, максимум кроны или уличное озеленение. |
| Целевое количество | Желаемое количество посадок; пустое поле — автоматический подбор. Это цель, а не гарантия размещения вне ограничений. |
| Seed / зерно | Воспроизводимость случайной части подбора кандидатов. |
| Макс. итераций | Ограничение числа попыток улучшения результата. |
| LLM-судья | Оценка мягких характеристик плана; при недоступной модели используется эвристика. Судья не устанавливает нормативную законность. |
| Отклонённые кандидаты | Отладочное отображение отклонённых точек. |
| Сетка чанков | Дополнительный отладочный слой; доступен в debug-режиме. |
| Сгенерировать план посадок | Запуск расчёта; требуется выбранная порода и готовый проект. |

Дополнительные настройки свёрнуты. Прогресс и этапы отображаются во время работы.

### Результат и аудит

Источники: `panels/QualityCard.tsx`, `LawnSection.tsx`, `RejectionsSection.tsx`, `views/AuditView.tsx`, `components/regulatory.tsx`.

- Сводка: деревья, кустарники, номер и выбранность итерации.
- Нормативный статус: соответствует / требует проверки / не соответствует. Для старой итерации без вердикта показывается переносимый на несколько строк текст «Соответствие: статус не рассчитан (старая генерация — перегенерируйте)».
- Нормативное покрытие: доля проверок по верифицированным правилам; блокеры объясняют ограничения вердикта.
- Метрики: покрытие, распределение, площадь крон и другие доступные показатели.
- Газон: рекомендуемые участки и площадь; не заменяет исходные CAD-поверхности.
- Причины отклонения: правила и объекты, из-за которых кандидат не был принят.
- Аудит: подробные проверки, статусы, применённые расстояния и ссылки на источники.
- Решение судьи об улучшении плана показано отдельно от нормативного статуса.

## 4. Карта, CAD и 3D

Источники: `viewer/ViewerCanvas.tsx`, `SceneManager.ts`.

| Элемент / жест | Действие |
|---|---|
| CAD / 3D-редактор | Переключение плоского чертежа и объёмной сцены. Проект открывается в CAD. |
| Перетаскивание в CAD | Сдвиг карты. |
| Перетаскивание в 3D | Вращение камеры; правая/средняя кнопка — сдвиг. |
| Колесо | Масштаб CAD или приближение 3D. |
| F | Вписать участок в область просмотра; работает вне текстового ввода. |
| Клик по посадке / зоне | Выбор объекта и открытие инспектора. |
| Перетаскивание выбранной посадки | Перемещение с живой проверкой и последующим сохранением. |
| Всплывающая аннотация | Причины допустимости/нарушений при наведении или перемещении. |
| Статус загрузки сцены | Временное сообщение о подготовке или ошибке; после успешной загрузки скрывается. |
| Светлая рамка | Будущий кадр фото; видна только во вкладке «Рендер». |
| Маркеры панорам | Готовые точки кликабельны и дают курсор-указатель; скрываются непрозрачными объектами. Видны только в режиме тура. |

Сенсорный экран: один палец — сдвиг CAD/вращение 3D, два пальца — масштаб и сдвиг; выбор объекта — касание. Отдельный режим прогулки с перетаскиваемым человеком удалён. Ракурс «С уровня человека» в фото-настройках — только пресет камеры.

## 5. Правая панель 3D: общие поля

Источник: `components/RenderWorkflow.tsx`. Ширину панели можно менять за левую границу. На узком экране панель располагается под сценой.

Вкладка **Тур** выбрана по умолчанию. **Рендер** показывает только фото-инструменты. Переключение сохраняет параметры и фоновый прогресс; переходы поддерживают системную настройку уменьшения анимации.

| Общее поле | Значение / влияние |
|---|---|
| Сезон | Весна, лето, осень, зима. Синхронизирует сцену, новые фото и новые панорамы. |
| Возраст посадок | При посадке, 5, 15, 30 лет или зрелые. Меняет высоту и ширину крон по существующей модели роста пород. |
| План | Итерация, для которой отображаются посадки и запускается визуализация. |
| Геометрия из CAD | Сворачиваемые параметры реконструкции. |
| Высота зданий без данных CAD | Резервная высота 2–200 м; исходная CAD-высота имеет приоритет. |
| Моделировать ограждения из CAD | Включение распознанных ограждений. |
| Перестроить 3D-сцену | Применение параметров реконструкции. Исходный CAD не переписывается. |

Возраст и сезон относятся к визуализации. Нормативная проверка и DXF используют взрослые размеры растений. Старые изображения не меняются после переключения полей: нужен новый запуск.

### Вкладка «Тур»

Источник: `components/PanoramaPanel.tsx`.

| Поле / кнопка | Назначение |
|---|---|
| Точек в туре | 6, 12 или 20 точек; больше точек — больше времени. По умолчанию 6. |
| Качество | Черновик 2K, высокое 4K, максимум 8K. По умолчанию черновик. |
| Высота глаз | 1,6 м, 5 м, 15 м или 40 м над землёй в точке панорамы. |
| Объёмная трава | Геометрические травинки рядом с точкой; зимой отключены. |
| Создать тур автоматически | Подбор точек и связей, затем последовательный Cycles-рендер. На текущем CPU-сервере тур может занимать часы. |
| Прогресс панорам | Готовые точки, общий процент, очередь и оценка оставшегося времени. |
| Добавить точку вручную | Раскрытие ручного выбора. |
| Указать кликом / Отменить выбор | Выбор места на земле / отмена выбора. При уходе во вкладку «Рендер» выбор отменяется. |
| Центр экрана | Определение точки по текущему виду. |
| Рендер точки | Отдельная панорама выбранной позиции. |
| X, Y, направление | Координаты и направление выбранной ручной точки. |
| Список туров/точек | Число точек, высота, сезон, возраст, готовность/ошибка и качество. |
| Открыть | Просмотр готовой панорамы из соответствующего задания. |
| ✕ в строке задания | Удаление завершённого/ошибочного задания; активное нельзя удалить этой кнопкой. |

Сезон в Cycles меняет листву, материалы земли и свет; зимой листопадные растения без листвы, газон становится снежным. Возраст масштабирует растения. Высота глаз меняет позицию камеры, качество — разрешение и стоимость рендера.

### Просмотр панорамы

Источник: `viewer/PanoramaViewer.tsx`.

- Информационная плашка: номер точки, число точек, высота глаз, сезон, возраст, направление взгляда и доступные переходы.
- «Скачать»: изображение текущей точки; кнопка оформлена так же, как остальные действия.
- «Полный экран» / F: системный полноэкранный просмотр, если он доступен.
- «Закрыть» / Escape: выход из просмотра.
- Перетаскивание: осмотреться; колесо: приближение; переходы по стрелкам/земле и мини-карте.
- W/↑ и S/↓: шаг по доступным точкам, A/D: поворот.
- Мини-карта: точки, текущая позиция и направление взгляда.
- Подсказка, загрузка и ошибки появляются по ситуации.

### Вкладка «Рендер»

Источник: `components/RenderWorkflow.tsx`.

| Поле / кнопка | Назначение |
|---|---|
| Пресет | Солнечный рекламный, естественный, вечерний или свой вариант. Выставляет свет и детализацию. |
| Соотношение сторон | 16:9, 4:3, 1:1, 3:4, 9:16 либо как в редакторе; задаёт рамку и кадр. |
| Разрешение | 512, 768, 1024, 1536 или 2048 пикселей по длинной стороне. HD-варианты требуют готового локального апскейлера. |
| Окружение | Исходная CAD-геометрия или добавленный парк вне участка. Сезон учитывается при генерации. |
| Освещение | Солнечное, дневное, вечернее, облачное. Ручная настройка переводит пресет в «Свой вариант». |
| Детализация | Сила преобразования входа моделью, 0,55–0,95; высокая сила может сильнее переосмысливать внешний вид. |
| Ракурс | Текущая камера, сверху или с уровня человека. После применения пресета снова показывается текущая камера. |
| Сгенерировать 3D-рендер | Сохранение плана, камеры, цветового, глубинного и семантического входа и запуск локальной фотомодели. |
| Прогресс генерации | Этап, процент, очередь и оценка времени. |
| Готовое изображение / Скачать | Результат, план и размеры изображения. |
| Улучшить рендер | История уточнений результата. |
| Пожелание к рендеру / Отправить | Текстовое уточнение внешнего вида через локальную LLM. Для другого выбранного плана сначала нужен его рендер. |

Здания в редакторе светлые без текстур; при съёмке для модели временно применяются фото-материалы. После съёмки материалы редактора восстанавливаются. Фото — иллюстрация на основе CAD, а не гарантированно точная фотографическая реконструкция.

## 6. Инспектор и строка состояния

Источники: `components/Inspector.tsx`, `BottomSheet.tsx`, `StatusBar.tsx`.

Инспектор открывается **внизу под просмотром** на настольном экране; на мобильном используется нижняя выдвижная панель.

| Элемент | Содержимое |
|---|---|
| Выбранная посадка | Порода, тип, признак ручного перемещения, id, положение X/Y, радиус кроны, итерация и оценка. |
| Расстояния | До здания, дороги, тротуара, сети, границы, существующего дерева и ближайшей посадки — при наличии соответствующих данных. |
| Проверки | Правило, измеренное/требуемое расстояние, статус, документ/пункт, статус источника, дополнительные цитаты и причина допустимости/нарушения. |
| Выбранная зона | Категория запрета, исходный объект и правило формирования зоны. |
| Закрыть инспектор | Сброс выбора. |
| Нижняя мобильная панель | Текущий раздел или инспектор; ручка меняет степень раскрытия. |
| Строка состояния | Координаты курсора X/Y в метрах, текущий этап или ошибка расчёта. |
| Debug-режим | Дополнительно масштаб, количество объектов и технические слои; не является обычным пользовательским режимом. |

## 8. Нормативы и история запусков

### Нормативы

Источник: `components/views/RegulationsView.tsx`, API `regulations/router.py`.

- Список документов: выбор документа и сведения о его обработке.
- Загрузка документа в интерфейсе: PDF или DOCX. API дополнительно поддерживает RTF; текстовые условия создаются отдельным запросом. Обработка зависит от доступности извлечения текста.
- Ручной ввод текста условия доступен на шаге «Условия» в «Конфигурации».
- Извлечение: получение кандидатов условий из документа.
- Фильтр кандидатов: все, требуют проверки, извлечено, проверено, активно, деактивировано, отклонено.
- Карточка кандидата: извлечённое правило, значение/единица, типы объектов, фрагмент и результат проверки.
- «Проверить»: проверка цитаты и извлечённого значения.
- «Изменить»: значение, единица, типы объектов; «Сохранить»/«Отмена».
- Подтверждение, отклонение, активация и деактивация управляют жизненным циклом условия. Неподтверждённый кандидат не равен действующей норме.

### Запуски

Источник: `components/views/RunsView.tsx`.

Таблица группирует результаты расчётов. Поля: итерация, число деревьев/кустарников, нарушения, покрытие, распределение, площадь крон. Выбор итерации открывает её как текущий план для просмотра, экспорта и визуализации.
