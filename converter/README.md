# dwg2dxf_tree

Рекурсивная конвертация дерева DWG → DXF с сохранением структуры папок.

Скрипт обходит указанную папку и все её подпапки, находит `*.dwg` и раскладывает
результат в **параллельное дерево** рядом с исходным. Папки, в поддереве которых
нет ни одного DWG, в выходном дереве не создаются.

## Установка движка (обязательно)

DWG — закрытый бинарный формат, чистым Python его не прочитать (`ezdxf` умеет
только DXF). Нужен внешний конвертер. Скрипт находит его сам.

**Вариант 1 — ODA File Converter (рекомендуется).** Бесплатный, от Open Design
Alliance, держит все версии DWG с R12 по 2018+:
<https://www.opendesign.com/guestfiles/oda_file_converter> (нужна бесплатная
регистрация). После установки путь определится автоматически; если нет — задайте
`--oda-path "C:\Program Files\ODA\ODAFileConverter 25.4\ODAFileConverter.exe"`
или переменную окружения `ODA_FILE_CONVERTER`.

**Вариант 2 — LibreDWG.** Утилита `dwg2dxf` должна быть в `PATH`. Ставится без
регистрации, но хуже поддерживает свежие версии DWG и может терять часть
объектов.

Python-зависимостей нет, достаточно Python 3.10+.

## Использование

```
python dwg2dxf_tree.py <папка с DWG> [опции]
```

Минимальный запуск:

```
python dwg2dxf_tree.py "C:\proj\drawings"
```

Получится:

```
C:\proj\drawings\          C:\proj\drawings_dxf\
├── план.dwg               ├── ACAD2018\
├── Этаж1\                 │   ├── план.dxf
│   └── узлы.dwg           │   └── Этаж1\
├── Этаж2\                 │       └── узлы.dxf
│   └── чертёж.dwg         ├── ACAD2013\
└── Фото\                  │   └── ... (то же дерево)
    └── скан.jpg           └── ACAD2010\
                               └── ... (то же дерево)
```

`Фото\` не дублируется — там нет DWG.

## Опции

| Опция | Назначение |
| --- | --- |
| `-o, --output DIR` | выходная папка (по умолчанию — рядом со входной, суффикс `_dxf`) |
| `--versions VER...` | версии DXF; по умолчанию `ACAD2018 ACAD2013 ACAD2010` |
| `--layout {version-dirs,flat}` | `version-dirs` (по умолчанию): `<выход>/ACAD2018/<структура>/файл.dxf`; `flat`: `<выход>/<структура>/файл.ACAD2018.dxf` |
| `--engine {auto,oda,libredwg}` | движок; `auto` — сначала ODA, затем LibreDWG |
| `--oda-path PATH` | явный путь к `ODAFileConverter.exe` |
| `--audit` | аудит/починка чертежей в ODA: медленнее, но вытягивает битые DWG |
| `-j, --jobs N` | параллельные процессы (по умолчанию 1 для ODA, 4 для LibreDWG) |
| `--timeout SEC` | таймаут одной операции, по умолчанию 600 |
| `--skip-existing` | не переделывать готовые DXF — продолжение после обрыва |
| `--dry-run` | показать план работ, ничего не писать |
| `-q, --quiet` | без построчного прогресса |

Доступные версии: `ACAD2018`, `ACAD2013`, `ACAD2010`, `ACAD2007`, `ACAD2004`,
`ACAD2000`, `ACAD14`, `ACAD13`, `ACAD12`.

## Примеры

```
# посмотреть план, ничего не трогая
python dwg2dxf_tree.py "C:\proj\drawings" --dry-run

# только одна версия, в другой диск
python dwg2dxf_tree.py "C:\proj\drawings" -o "D:\dxf" --versions ACAD2018

# продолжить после обрыва
python dwg2dxf_tree.py "C:\proj\drawings" --skip-existing

# битые чертежи — с аудитом
python dwg2dxf_tree.py "C:\proj\drawings" --audit
```

## Поведение и гарантии

- **Пустые папки не создаются.** Каталог в выходном дереве появляется только в
  момент записи файла. Если DWG не сконвертировался — папка не остаётся.
- **Исходники не трогаются**: только чтение.
- Если выходная папка оказалась внутри входной, скрипт в неё не заходит —
  повторного прогона по собственному результату не будет.
- Расширение проверяется без учёта регистра (`.dwg`, `.DWG`). Временные файлы
  AutoCAD (`~$*`) пропускаются.
- Код возврата: `0` — всё успешно, `1` — были ошибки конвертации (список
  печатается в конце), `130` — прервано по Ctrl+C.
- Успех определяется по фактическому наличию непустого DXF, а не по коду
  возврата конвертера — ODA File Converter часто возвращает 0 при провале.

## Замечания по движкам

- **ODA** работает пакетно, по папке целиком, поэтому `--skip-existing`
  пропускает папку только если в ней готовы *все* файлы этой версии; иначе папка
  пересчитывается целиком, но на диск ложатся только недостающие файлы.
- **ODA** — приложение на Qt и на Windows на мгновение показывает окно. Несколько
  одновременных копий оно переносит плохо, поэтому по умолчанию `--jobs 1`.
  Поднимайте осознанно.
- **LibreDWG** работает по одному файлу, здесь параллелизм безопасен.
